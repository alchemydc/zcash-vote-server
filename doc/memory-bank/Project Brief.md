# Project Brief

## Overview
Infrastructure tooling to create and run the zcash-vote-server infrastructure in public clouds, hybrid clouds, or bare metal.

## Core Features
- Terraform/Opentofu tooling to provision infrastructure for zcash-vote-server in GCP
- Ansible tooling to build, configure and run the zcash-vote-server

## Target Users
Technical users responsible for building and running the zcash-vote-server validators.

## Technical Preferences (optional)
- GCP
- Terraform/Opentofu
- Git
- zcash-vote-server
